========================================
TROUBLESHOOTING
========================================

If you encounter issues:

1. Check pod status:
   kubectl get pods -n {{ .Release.Namespace }}

2. Describe pod for events:
   kubectl describe pod <pod-name> -n {{ .Release.Namespace }}

3. View logs:
   kubectl logs <pod-name> -n {{ .Release.Namespace }} -c <container-name>

4. Check Dapr sidecar:
   kubectl logs <pod-name> -n {{ .Release.Namespace }} -c daprd

5. Verify Dapr installation:
   dapr status -k

6. Check components:
   kubectl get components -n {{ .Release.Namespace }}
