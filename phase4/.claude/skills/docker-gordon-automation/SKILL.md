## When to Use
Use when building and optimizing Docker images using Docker AI (Gordon).

## Process
1. Enable Docker AI (Gordon)
2. Scan project structure
3. Generate Dockerfile
4. Optimize image layers
5. Fix build issues
6. Test container locally
7. Push to registry

## Output Format
- Dockerfile
- Build command
- Image tag
- Push instructions

## Example

### Input
FastAPI backend project

### Output
```bash
docker ai "Generate optimized Dockerfile for FastAPI app"
```
