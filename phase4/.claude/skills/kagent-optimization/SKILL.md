## When to Use
Use when analyzing performance and resource usage.

## Process
1. Install Kagent
2. Scan cluster
3. Detect issues
4. Analyze workloads
5. Recommend fixes
6. Apply optimizations
7. Monitor results

## Output Format
- Health report
- Resource analysis
- Optimization plan

## Example

### Input
Check cluster health

### Output
```bash
kagent "analyze cluster health"
```
