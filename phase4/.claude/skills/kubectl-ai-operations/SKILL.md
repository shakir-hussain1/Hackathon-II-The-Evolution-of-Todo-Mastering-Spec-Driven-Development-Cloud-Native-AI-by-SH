## When to Use
Use when managing Kubernetes using natural language.

## Process
1. Install kubectl-ai
2. Connect cluster
3. Run AI commands
4. Review output
5. Apply changes
6. Monitor status

## Output Format
- Generated kubectl commands
- Status report
- Optimization notes

## Example

### Input
Scale backend pods

### Output
```bash
kubectl-ai "scale backend to 3 replicas"
```
